# 異獸 AI 生圖提示詞

每隻異獸做成 **1024×1024、白底或去背的 PNG**，在 App 的「美術工作室」拖進對應的格子就會套用。

## 讓畫風一致的做法
1. 每張圖都在前面貼上同一段「共用風格」。
2. 先畫基礎型，滿意後把基礎型的圖一起丟給 AI，說「這是同一隻生物的進化型」，再貼進化型的提示詞，前後才會像同一隻。
3. 不要寫任何現有作品或角色的名字（例如寶可夢），只描述你要的樣子。
4. 想商業化的話，最後請繪師依 AI 圖重繪或大幅修改，角色才確定是你的。

## 共用風格

```
original creature design for a monster-collecting RPG, single creature, full body, three-quarter view, dynamic heroic pose, clean cel-shaded anime illustration, bold confident lineart, vibrant but limited color palette, strong readable silhouette, soft rim light, pure white background, no text, no watermark, no logo
```
